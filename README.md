# Fundación Ejército de los Andes

Sitio web oficial de la **Fundación Ejército de los Andes**, institución territorial nacida en el conurbano bonaerense orientada a promover procesos de transformación social, cultural, educativa y audiovisual.

🌐 **Web:** [fundacion-ejercito-andes.pages.dev](https://fundacion-ejercito-andes.pages.dev)

---

## Estructura del proyecto

```
fundacion-ejercito-andes/
├── index.html          → Página principal
└── assets/
    └── img/            → Fotos y recursos gráficos
```

## Secciones de la página

- **Hero** — Video aéreo de Fuerte Apache de fondo
- **Quiénes somos** — Identidad y misión institucional
- **Ejes de acción** — Los 7 ejes de trabajo de la fundación
- **Proyectos en el barrio** — Mural Club Patria Ingenieros
- **Actividades comunitarias** — Slider de eventos y actividades
- **Proyecto Fuerte Apache** — Eje territorial principal
- **Contenido audiovisual** — Producciones de la fundación
- **Casa EDA** — Espacio físico comunitario
- **Donaciones** — Sección de apoyo institucional

## Tecnologías

- HTML5 / CSS3 / JavaScript vanilla
- Fuentes: Syne + Syne Mono + Libre Baskerville (Google Fonts)
- Sin frameworks ni dependencias externas
